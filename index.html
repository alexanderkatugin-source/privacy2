Политика конфиденциальности приложения «Дневник: Остаток в баке»

Настоящая политика конфиденциальности описывает, как приложение «Дневник: Остаток в баке» (далее — Приложение) обрабатывает данные пользователей.

1. Какие данные собирает Приложение

Приложение не собирает персональные данные пользователей. В процессе использования могут обрабатываться только следующие данные:

  • Данные о заправках: объём топлива, цена за литр, пробег, дата и время заправки.
  • Настройки приложения: выбранный формат отображения, язык интерфейса (если есть).

Эти данные используются исключительно для расчёта статистики и формирования отчётов внутри Приложения.

2. Где и как хранятся данные

Все данные хранятся локально на устройстве пользователя в LocalStorage браузера/WebView. Приложение не передаёт данные на серверы разработчика или третьим лицам. При удалении Приложения все данные будут безвозвратно удалены с устройства.

3. Использование интернета

Для формирования отчётов в форматах PDF и Excel Приложение загружает необходимые библиотеки из сети. Это происходит только в момент нажатия кнопки «Скачать отчёт». Никакие пользовательские данные при этом не передаются.

4. Изменения в Политике

Разработчик оставляет за собой право вносить изменения в настоящую Политику конфиденциальности. Актуальная версия всегда доступна по адресу: https://alexanderkatugin-source.github.io/privacy2/.

5. Контакты

По вопросам, связанным с обработкой данных, вы можете обратиться к разработчику по адресу: a.v.katugin@gmail.com.
